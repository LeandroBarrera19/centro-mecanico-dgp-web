## La cuestión de los finales de línea

Comprobado **a nivel de bytes**, sin confiar en `git ls-files`:

```
public/index.html   bytes 92229  LF 2003  CR 0  CRLF 0  termina en \n: True
git ls-files --eol  →  i/lf w/lf
git diff --numstat  →  1 8 public/index.html
```

Cero `\r` en todo el archivo. No quedó ningún resto. Pero el revisor fue más
allá y encontró **la causa de fondo**, que yo no había mirado:

> `git config core.autocrlf` está en `true` y no hay `.gitattributes`, que es
> exactamente lo que hace que el problema reaparezca cada vez que se usa `git
> stash`. Está fuera de esta unidad, pero es la causa de fondo y no la
> resolvió nadie todavía.

→ **Anotado como P-044.**
